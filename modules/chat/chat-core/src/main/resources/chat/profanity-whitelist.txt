#   자체 Aho-Corasick(ProfanityFilter)을 쓰고, 필요한 것은 사전뿐이었다.
#
# 제외한 카테고리와 이유:
#   CHINESE_PROFANITY_PATTERNS (1,155)  한국어 서비스라 무관. trie 메모리만 늘린다.
#   POLITICS_PROFANITY_PATTERNS   (33)  정치인 별칭이라 라이브 커머스 채팅에서 가릴
#                                       대상인지 불분명하고 오탐 민원이 생기기 쉽다.
#
# ⚠️ 화이트리스트는 korcen 원본(496)에서 <b>290</b>으로 줄였다. 기준은 우리 필터의 의미에서
#   기계적으로 나온다 — ProfanityFilter.isWhitelisted 가 "토큰이 화이트리스트 항목을 <b>포함</b>하면
#   그 토큰 전체를 보존" 이라, 안에 욕설이 없는 항목은 보호할 대상이 없고 우회로만 만든다.
#   실측(원본 그대로 넣었을 때):
#     너가시발   -> 너가시발   (통과)   '너가' 가 화이트리스트라 토큰 전체가 보존됨
#     카카오시발 -> 카카오시발 (통과)   '카카오' 때문
#     0개시발    -> 0개시발    (통과)   '0개' 때문
#   선별본에서는 셋 다 '너가***' 처럼 마스킹되고, 보호가 필요한 '시발점' 은 그대로 남는다.
#
# ⚠️ 남은 좁은 갈래 36건이 있다 — 'ㅈㅗ'·'ㅗ로' 같은 2글자 자모 항목과 '쫒다'·'줫다' 오타형이다.
#   'ㅗ' 를 욕설로 넣은 데서 오는 비용이고, 'ㅈㅗ시발' 같은 토큰이 통과한다. 그 36건을 지우면
#   'ㅈㅗ'(조) 오타가 마스킹되므로 지금은 오탐 쪽을 피하는 선택을 했다.
#
