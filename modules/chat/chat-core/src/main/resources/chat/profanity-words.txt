#   1) VaneProject/bad-word-filtering  — 기본 사전. 이 저장소의 설계 단계에서 이미 큐레이션해 둔

#      선례다(보지·자지를 "해보지·입어보지·자지마" 때문에 뺀 판단).
#   2) Tanat05/korcen            — 우회 변형만 보강. 기호·숫자·자모 섞인 형태(s1bal · ㅆㅣ · @ㅐ미)와
#      3글자 이상 합성형. korcen 은 매칭 전에 씨→시 같은 정규화를 하고 그 전제로 목록을 쓰므로
#      기본 표기가 목록에 없다. 우리 필터는 정규화를 하지 않아 기본 표기는 1)에서 받는다.
#
# 뺀 것 — 한국어 형태소와 겹쳐 화이트리스트로 못 막는 계급. 화이트리스트는 '토큰이 항목을 포함하면
# 보존' 이라 홀로 선 짧은 욕설을 덮으려면 항목이 그 단어와 같아야 하는데, 그러면 진짜 욕설이 풀린다.
#   새끼   새끼 고양이 · 강아지 새끼 (반려동물 커머스)
#   세끼   하루 세끼
#   호로   번호로 · 암호로 · 신호로 (조사 '로' 가 붙는 모든 '…호' 명사)
#   개떡   쑥개떡 (식품 커머스)
#   유방   유방 확대 (뷰티·건강 커머스). '유방암' 만 화이트리스트에 있어서 단독형은 가려졌다 —
#          해부어는 화이트리스트 열거로 끝나지 않는다는 증거다.
#   유두   유두 보호기 · 수유 유두크림 (육아 커머스)
#   고환   고환 검사 · 한우 고환 (건강·축산 커머스)
#   후장   後場 — 후장 시세 · 후장 마감 (주식 방송)
#   똥     똥손 · 소똥 · 똥배 (1글자라 결합이 무제한)
#   수셔   허리가 쑤셔요
#   쑤셔   허리가 쑤셔요
#   졸라   졸라요 · 졸라네 · 졸라댔어요 (조르다의 활용). 활용형 넷을 화이트리스트에 열거해
#          봤지만 '유방암' 과 같은 모양이었다 — 열거로는 안 닫힌다. 같은 뜻의 '존나' 는 남는다.
#   sex    unisex · Essex · Sussex · BusinessException. 섹 계열 한글 항목 16건(섹스 · 섹쓰 ·
#          룸섹스 …)은 그대로 남는다. 빼면 ASCII 자판만으로 사전을 끄는 우회로도 같이 사라진다 —
#          'sex' 를 지키려고 두었던 화이트리스트 sexual · sexy 가 없어지면서 sexyfuck ·
#          sexy시발 이 다시 잡힌다.
#   siva   passivation · passivate (스테인리스 부동태 처리 — 조리기구 설명에 나온다).
#          위 sex 를 뺄 때 '라틴 항목 중 영단어에 걸리는 것은 그것 하나뿐' 이라고 적었는데
#          틀렸다. 한 라운드 뒤에 이것이 나왔다 — 수를 세지 말고 계급을 재야 한다.
#   보지 · 자지는 위 1)의 출처 단계에서 같은 이유로 이미 빠져 있다.
#   색스 · s스 · x스 · se스 (2026-11-03, 저장소 한국어 코퍼스 32,049토큰 스윕에서 나왔다)
#          '섹스' 의 변형 표기인데 2A 가 토큰 안의 기호를 떼어낸 뒤에 걸려 평범한 말을 통째로
#          가렸다 — 'DB/Redis/검색/스토리지' → *** (색스), 'as("스레드' → *** (s스).
#          색스는 화이트리스트로 못 막는다. 2A 는 우회로 판단한 토큰을 보정 없이 가리는 쪽으로
#          이미 결정돼 있고(머리글의 시1발점 결정) 그걸 뒤집으면 그 결정이 깨진다.
#          ASCII 한 글자 + '스' 계급(s스 · x스 · se스)은 보호값이 거의 없다 — 'ㅅ스' 를
#          그렇게 적는 사람보다 영문 낱말 뒤에 '스' 가 붙는 토큰이 훨씬 많다. 섹스 · 쌕스 ·
#          세엑스 · 쉐엑스 · 룸섹스 는 그대로 남는다.
#   유방·유두·고환·후장은 1)의 머리글이 "보류 — 톤 정책 결정 필요" 로 이름을 적어 둔 10건에서
#   왔다. 그 목록의 나머지는 가리는 쪽으로 결정했다(2026-11-02):
#     양아치 · 쪼다 · 허접 · 노옴 · 허덥   약한 속어다. 상품 설명어가 아니라 말투 문제이고,
#                                         판매자에게 날아오는 비하도 같이 거르는 쪽을 택했다.
#     성교                                단독형은 가린다. '성교육' 은 화이트리스트가 덮고
#                                         '인성교육'·'학교성교육' 처럼 그것을 품은 토큰도 같이
#                                         덮인다. 다만 '성교' 뒤가 '육' 이 아니면 안 덮인다 —
#                                         여성교사 → 여***사 · 음성교환 → 음***환 ·
#                                         여성교복 → 여***복 (실측). 띄어 쓰면 걸리지 않는다.
#   ('거시기' 는 보류가 아니라 1)의 '제거 23건' 쪽이다 — 세지 말 것.)
#
# 길이별 구성. 아래 넷은 '순한글 음절만' 기준이다(936/1102) — 전체 기준으로 세면 다른 수가
# 나오니 범위를 보고 세라.
#   순한글: 1글자 7 · 2글자 173 · 3글자 488 · 4글자 이상 268
#   비순한글 166건은 기호·자모·ASCII 가 섞인 형태이고 그중 115건이 1~3자다(18놈 · @ㅐ미 · ㅅㅂ · t발).
# 오탐의 원천은 '짧은 순한글' 계급이라 korcen 보강분에서는 2글자 이하 순한글을 받지 않았다.
# 남아 있는 것은 전부 1)에서 온 것이고, 1)이 이미 큐레이션한 뒤 "보류" 로 이름까지 적어 둔 목록을
# 위에서 한 번 더 걸렀다. 여기에 새 짧은 항목을 더하려면 오탐 회귀를 돌려야 한다.
# (이 수를 고칠 때는 사전을 실제로 세고 고친다 — 위 '뺀 것' 이 늘면 여기가 같이 틀어진다.
#  셀 때 기준을 바꾸지 말 것: 위 넷은 [가-힣]만으로 이뤄진 항목만 센 수다.)
# korcen 에서 예외로 받은 좆 · 좃 · 졷 · 좈 · 줮 · 촟 · 썅 일곱은 모두 1글자 순한글이다(= 위 '1글자' 전부).
#
# 알고 남긴 오탐 — 전부 화이트리스트로는 못 닫는다(잔여가 한글이 아니면 규칙 (3)에 걸린다).
#   3개년      '개년' 에 걸린다. 막으려면 '개년' 자체를 화이트리스트에 넣어야 하는데 그건 진짜
#              욕설을 푼다. 라이브 커머스 채팅에서 '3개년' 보다 '개년' 이 나올 확률이 높다고 봤다.
#   여성교사류  위 '성교' 항목 참조.
#   영단어 5건  순 ASCII 항목 28건을 영어 사전 전수와 대조한 결과다. 잔여가 라틴이라
#              화이트리스트로 못 넣고(규칙 (3)), 한국어 라이브 커머스에 나올 확률이 낮다고 보고
#              전부 욕설 쪽을 남겼다. 상품 설명어였던 passivation(siva) · BusinessException(sex)
#              은 그래서 뺀 것이고, 아래는 성격이 다르다.
#                pussy  -> pussycat · pussyfoot · pussytoe …  7건
#                penis  -> hemipenis · micropenis · penistone  4건
#                sipal  -> fissipalmate · fissipalmation       2건
#                sival  -> passival · possessival              2건
#                pennis -> pennisetum (수크령 속명)             1건
#
#              재확인하는 법(2026-11-03 기준, /usr/share/dict/web2 235,976 단어):
#                sh .claude/scripts/check-ascii-entries.sh
#              절차는 그 스크립트 하나에만 있다 — 여기에 복사본을 두면 스크립트를 고쳐도
#              아무도 안 보는 쪽만 고쳐진다. 목록이 없으면 스크립트가 exit 2 로 실패한다.
#              이 목록은 테스트에 들이지 않는다 — OS 제공 파일이라 CI 이미지에 없으면 검사가
#              조용히 초록이 된다. 대신 ProfanityDictionaryTest 가 ASCII 항목 28건의 집합 자체를
#              고정해, 하나를 더하려면 테스트를 고쳐야 하고 고치려면 이 문단을 보게 된다.
#
# 알고 남긴 미탐 — 뺀 것의 대가다. '뺀 것' 목록이 왜 뺐는지만 적고 무엇을 잃었는지는 안 적어서
# 따로 센다.
#   졸라       사전에 '졸라' 를 품은 항목이 0건이다. 뜻이 같은 '존나'·'존나게' 가 남지만 표기는
#              커버되지 않는다 — '졸라 비싸' 는 통과하고 '존나 비싸' 만 걸린다.
#   보지 · 자지 · 새끼 · 세끼 · 유방 · 유두 · 고환 · 후장 · 호로 · 개떡 · 똥 · 수셔 · 쑤셔 · sex · siva
#              각 항목의 합성형은 대부분 따로 등재돼 있지만(개새 · 개보지 · 룸섹스 …) 단독형은
#              통과한다. 오탐을 피하려고 고른 대가이고, 이 선택은 '뺀 것' 에 근거를 적어 뒀다.
#   색스       단독형이 통과한다. '섹스' 로 적으면 걸린다. 위 '뺀 것' 참조.
#   조합용 자모로만 적은 표기 7건 (2026-11-03 실측)
#              자모 항목의 자모를 전부 조합용(U+1100–11FF)으로 바꿔 적으면 입구 NFC 가
#              음절로 합쳐 버리고 그 음절이 사전에 없다 — ㅅㅣㅂㅏ → 시바 · ㅆㅐㄲㅑ → 쌔꺄 ·
#              ㄱㅐㅈㅏ → 개자 · ㅆㅣ → 씨 · 보ㅈㅣ → 보지 · 시ㅂㅏ → 시바 · ㅅㅔㅅㄱ.
#              닫는 길은 그 음절(시바 · 보지 · 씨 · 개자)을 사전에 넣는 것뿐인데, 그것들은 위
#              '뺀 것' 이 오탐 때문에 일부러 뺀 낱말이다(시바견 · 보지 못했다 · 김씨). 그래서
#              닫지 않는다. 종성·반각·조합용 자음 표기는 모두 막힌다(ProfanityFilter 의 fold).
#
# 한 줄에 한 단어. '#' 로 시작하는 줄과 빈 줄은 무시한다. 항목이 둘 중 하나면 로더가 거부하고
# 부팅이 실패한다 — 공백이나 보이지 않는 글자(NBSP · ZWSP · 워드조이너 · BOM · 한글 채움문자 넷)가 들었거나, 64자를 넘거나(정본 chat_filter_word.word 가
# varchar(64) 다). 같은 거부가 설정 CSV(chat.profanity.words · chat.profanity.whitelist)에도 걸린다.
# 대소문자는 로더가 아니라 ProfanityFilter 가 정규화한다(ASCII 소문자화).
